# Snow Jok

Запустите Snow Jok на рабочем столе, где видна панель Dock. Снег, сугроб и техника остаются на этом рабочем столе основного экрана при переключении пространств macOS. Сугроб отображается поверх окон и Dock и пропускает клики. Нажмите на технику в углу экрана, чтобы она проехала вдоль него и убрала снег. Следующий клик отправит её обратно.

Snow Jok работает в строке меню macOS. Нажмите на снежинку, чтобы открыть настройки. В подменю «Скорость падения» можно выбрать от 25 до 200 %, а в подменю «Плотность снега» — от 25 до 200 %. Значение 100 % соответствует исходному снегопаду. Настройки применяются сразу и сохраняются после перезапуска.

Язык интерфейса определяется при запуске. Для русского языка системы используется русский, для остальных языков — английский.

В подменю «Техника для уборки» можно выбрать экскаватор, снегоуборочную машину, снегоход или Деда Мороза на санях. Выбор применяется сразу и сохраняется после перезапуска.

В меню также можно убрать снег вручную или включить «Автоматическую уборку». В этом режиме уборка начинается, когда самая высокая точка сугроба превышает 60 % максимальной высоты. По умолчанию режим выключен. Выбранное состояние сохраняется после перезапуска.

Выйти из приложения можно через меню снежинки или по правому клику на технике.

## Сборка и запуск

Нужны macOS, JDK 25 и Maven. Приложение использует Swing и Java 25 FFM для доступа к AppKit.

```sh
export JAVA_HOME=$(/usr/libexec/java_home -v 25)
mvn package
"$JAVA_HOME/bin/java" -jar target/snow-jok.jar
```

Чтобы собрать приложение для Finder, запустите:

```sh
sh package-macos.sh
open "target/macos/Snow Jok.app"
```

Внутри `.app` уже есть среда Java для архитектуры Mac, на котором выполнена сборка. `jpackage` использует инструменты из Xcode Command Line Tools.
